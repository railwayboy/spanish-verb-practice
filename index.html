3 · CAR / GAR / ZAR

Yo-form spelling changes

Only the yo form changes spelling to preserve the sound.

  • -car → -qué: buscar → busqué
  • -gar → -gué: llegar → llegué
  • -zar → -cé: empezar → empecé
Other forms stay regular: buscaste, buscó, buscamos…
4 · VUJI stem families

Learn the irregular verbs by family

Each family uses the same preterite endings: -e, -iste, -o, -imos, -isteis, -ieron. These forms have no written accent marks.

U-stem family (the stem contains u)
  • andar → anduv-: anduve, anduvo, anduvieron
  • estar → estuv-: estuve, estuvo, estuvieron
  • tener → tuv-: tuve, tuvo, tuvieron
  • poder → pud-: pude, pudo, pudieron
  • poner → pus-: puse, puso, pusieron
  • saber → sup-: supe, supo, supieron
I-stem family (the stem contains i)
  • hacer → hic-: hice, hizo, hicieron
  • querer → quis-: quise, quiso, quisieron
  • venir → vin-: vine, vino, vinieron
J-stem family (third-person plural ends in -eron)
  • decir → dij-: dije, dijo, dijeron
  • traer → traj-: traje, trajo, trajeron
  • conducir → conduj-: conduje, condujo, condujeron
Vosotros is included in the pattern: anduvisteis, estuvisteis, tuvisteis, pudisteis, pusisteis, supisteis; hicisteis, quisisteis, vinisteis; dijisteis, trajisteis, condujisteis.

Spelling changes

Present-tense spelling-change verbs

  • -ger / -gir: g → j in the yo form: escoger → escojo; dirigir → dirijo.
  • -guir: gu → g in the yo form: seguir → sigo; distinguir → distingo.
  • -uir: add y in forms other than nosotros/vosotros: construir → construyo, construyes, construye, construimos, construís, construyen.
  • -iar / -uar: many verbs stress the í/ú in the yo, tú, él/ella, ellos forms: enviar → envío; actuar → actúo. Nosotros/vosotros usually do not carry that accent: enviamos, actuamos.
For -iar/-uar, the accent pattern depends on the verb. Learn common examples your class has covered (e.g., enviar, confiar, actuar, continuar).

Choosing the tense

Preterite vs. imperfect

Preterite = event / completed action

Ayer estudié dos horas. — Yesterday I studied for two hours.

La película empezó a las ocho. — The movie started at eight.

Imperfect = background / habit / ongoing past

Cuando era niño, jugaba afuera. — When I was a child, I used to play outside.

Estudiaba cuando llamaste. — I was studying when you called.

A helpful cue, not an absolute rule: preterite often advances the story; imperfect often sets the scene or describes what was going on.
